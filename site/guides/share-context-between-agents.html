Agent Memory API / Guides

Share Context Between Sales and Support Agents

A sales agent learns a customer escalates to legal over pricing. Two weeks later a support agent opens a ticket with that customer, knows none of it, and walks straight into the landmine. This guide connects them — without either agent owning the other's data.

What You Will Build

A sales agent that writes to its own namespace, a support agent that can read it, and a revocation path that cuts access instantly when the engagement ends. About fifteen minutes.

Prerequisites

  • A RapidAPI key for Agent Memory API
  • Two agent identifiers — here sales-bot-001 and support-bot-001
  • Python 3.9+ with httpx

Authentication

import os, httpx

BASE = "https://agent-memory-api.YOUR-NAME.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}
SALES, SUPPORT = "sales-bot-001", "support-bot-001"

Step 1 — Register Both Agents

An agent must exist before it can be named in a grant.

for agent_id, name in [(SALES, "Sales Bot"), (SUPPORT, "Support Bot")]:
    httpx.post(f"{BASE}/v1/agents", headers=HEADERS, json={
        "agent_id": agent_id, "display_name": name, "framework": "crewai",
    })

Step 2 — Sales Agent Writes to Its Own Namespace

Namespaces are how permission boundaries are drawn, so group facts by who should eventually read them — not by what they are about.

httpx.post(f"{BASE}/v1/memories", headers=HEADERS, json={
    "content": "Do not discuss pricing with Priya Raman at Acme; she escalates to legal immediately. Route pricing questions to Dana Whitfield.",
    "agent_id": SALES,
    "namespace": "acme-corp/sales/leads",
    "scope": "org",
    "importance": 0.95,
})

Step 3 — Confirm the Support Agent Cannot See It Yet

Isolation is the default. Verify it, so you know the grant in the next step is what changes the outcome.

r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
    "query": "who should I avoid discussing pricing with at Acme",
    "agent_id": SUPPORT,
})
print(r.json()["count"])   # 0

Step 4 — Grant Namespace Access

Grants are hierarchical. A grant on acme-corp/sales also covers acme-corp/sales/leads and everything below it, so grant the parent and let the tree fill in.

grant = httpx.post(f"{BASE}/v1/permissions", headers=HEADERS, json={
    "granter_agent_id": SALES,
    "grantee_agent_id": SUPPORT,
    "namespace": "acme-corp/sales",
    "permission": "read",
    "ttl_seconds": 90 * 86400,        # auto-revoke after the engagement
    "note": "Support needs lead context for the Acme migration",
}).json()

permission_id = grant["permission_id"]
Set grantee_agent_id to "*" to share with every agent on your account. Convenient, and exactly how a private note ends up in front of the wrong bot. Prefer naming agents explicitly.

Step 5 — Support Agent Recalls It

r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
    "query": "who should I avoid discussing pricing with at Acme",
    "agent_id": SUPPORT,
})
body = r.json()

for m in body["results"]:
    print(f"[{m['via']}] from {m['agent_id']}: {m['content'][:60]}")

print("contributed by:", body["agents_consulted"])

# [grant] from sales-bot-001: Do not discuss pricing with Priya Raman at Acme...
# contributed by: ['sales-bot-001']

Each result reports via: owned, grant, or share. Use it to attribute context in your prompt — "your colleague's sales agent noted..." reads better than presenting another agent's finding as your own.

Sharing a Single Memory Instead

For a one-off hand-off, grant the specific memory rather than the namespace.

httpx.post(f"{BASE}/v1/permissions", headers=HEADERS, json={
    "granter_agent_id": SALES,
    "grantee_agent_id": SUPPORT,
    "memory_id": "9f8b2c14-...",
    "permission": "read",
})

Step 6 — Revoke When the Engagement Ends

httpx.delete(f"{BASE}/v1/permissions/{permission_id}", headers=HEADERS)

# Verify
r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
    "query": "who should I avoid discussing pricing with at Acme",
    "agent_id": SUPPORT,
})
print(r.json()["count"])   # 0 again

Revocation takes effect on the next recall; cached results for your account are invalidated immediately. Audit what is currently open with GET /v1/permissions.

Complete Working Example

import os, httpx

BASE = "https://agent-memory-api.YOUR-NAME.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}


def register(agent_id: str, name: str):
    httpx.post(f"{BASE}/v1/agents", headers=HEADERS,
               json={"agent_id": agent_id, "display_name": name})


def grant_read(granter: str, grantee: str, namespace: str, days: int) -> str:
    r = httpx.post(f"{BASE}/v1/permissions", headers=HEADERS, json={
        "granter_agent_id": granter, "grantee_agent_id": grantee,
        "namespace": namespace, "permission": "read",
        "ttl_seconds": days * 86400,
    })
    r.raise_for_status()
    return r.json()["permission_id"]


def recall_with_attribution(agent_id: str, query: str) -> list[str]:
    r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS,
                  params={"query": query, "agent_id": agent_id, "limit": 6})
    r.raise_for_status()
    out = []
    for m in r.json()["results"]:
        prefix = "" if m["via"] == "owned" else f"(via {m['agent_id']}) "
        out.append(f"{prefix}{m['content']}")
    return out


register("sales-bot-001", "Sales Bot")
register("support-bot-001", "Support Bot")
pid = grant_read("sales-bot-001", "support-bot-001", "acme-corp/sales", days=90)

for fact in recall_with_attribution("support-bot-001", "Acme pricing escalation risk"):
    print(fact)

# When the engagement ends:
httpx.delete(f"{BASE}/v1/permissions/{pid}", headers=HEADERS)

Error Handling

StatusCauseFix
400Both namespace and memory_id sent, or neitherSend exactly one
400Granter equals granteeAn agent already sees its own memories
404Memory not owned by the granterOnly the owning agent can grant access to a memory
