Agent Memory API / Guides

Use Agent Memory from Claude and Cursor via MCP

The Model Context Protocol lets Claude Desktop, Claude Code, Cursor and Windsurf call tools directly. Point one at this server and your assistant gets durable memory across every conversation — with no integration code in your project at all.

What You Will Build

A local MCP server that exposes five tools to your assistant: remember, recall, forget, share_memory_with_agent and memory_stats. Five minutes.

Prerequisites

  • Python 3.10+
  • A RapidAPI key for Agent Memory API
  • An MCP-capable client (Claude Desktop, Claude Code, Cursor or Windsurf)

Step 1 — Install

git clone https://github.com/boirama/agent-memory-api.git
cd agent-memory-api
pip install -r mcp/requirements.txt

Step 2 — Configure Your Client

Claude Desktop reads claude_desktop_config.json — on macOS at ~/Library/Application Support/Claude/, on Windows at %APPDATA%\Claude\.

{
  "mcpServers": {
    "agent-memory": {
      "command": "python",
      "args": ["/absolute/path/to/agent-memory-api/mcp/server.py"],
      "env": {
        "AGENT_MEMORY_BASE_URL": "https://agent-memory-api.boirama.workers.dev",
        "AGENT_MEMORY_API_KEY": "your-rapidapi-key",
        "AGENT_MEMORY_RAPIDAPI_HOST": "agent-memory-api.p.rapidapi.com",
        "AGENT_MEMORY_AGENT_ID": "claude-desktop"
      }
    }
  }
}

Use an absolute path — MCP clients do not resolve relative ones. Restart the client afterwards; it only reads this file on launch.

Give each client its own AGENT_MEMORY_AGENT_ID — claude-desktop, cursor, claude-code. Memories are owned per agent, so distinct IDs are what make permission grants between your own tools meaningful. Use the same ID everywhere and they silently share one pool.

Step 3 — Use It

Once connected, the tools are available without you naming them:

You:    I always want Python examples to use httpx, never requests.
Claude: [calls remember]
        Noted — I'll use httpx in Python examples from now on.

--- new conversation, days later ---

You:    Show me how to call a REST endpoint in Python.
Claude: [calls recall]
        import httpx
        ...

Environment Variables

VariableRequiredPurpose
AGENT_MEMORY_BASE_URLyesYour Cloudflare Worker or RapidAPI gateway URL
AGENT_MEMORY_API_KEYyesRapidAPI key, or a direct bearer key
AGENT_MEMORY_RAPIDAPI_HOSTnoSet when going through RapidAPI; omit to call your Worker directly
AGENT_MEMORY_AGENT_IDnoOwner ID for memories this client writes. Defaults to mcp-client

The Tools

ToolWhen the model calls it
rememberThe user states a preference, decision, constraint or deadline worth keeping
recallConversation start, or the user refers to something with no context ("the usual", "like last time")
forgetThe user corrects a stored fact or asks for it to be deleted
share_memory_with_agentThe user wants another assistant or teammate's agent to have this context
memory_statsThe user asks what is stored, or wants to audit namespaces

Troubleshooting

SymptomCauseFix
Tools never appearClient did not restart, or the path is relativeUse an absolute path, then fully quit and relaunch
"Could not reach the memory API"Wrong base URL, or Railway is cold-startingOpen BASE_URL/health in a browser and retry
Every call returns 401Host header mismatchSet AGENT_MEMORY_RAPIDAPI_HOST when using the gateway; unset it when calling your Worker directly
Recall returns nothingAgent ID changed between sessionsMemories are owned per agent — keep the ID stable

Test the server standalone before blaming the client:

export AGENT_MEMORY_BASE_URL="https://agent-memory-api.boirama.workers.dev"
export AGENT_MEMORY_API_KEY="your-key"
python mcp/server.py
# Waits on stdio. No error output means it started cleanly.
