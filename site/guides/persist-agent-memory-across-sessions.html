Agent Memory API / Guides

Persist Agent Memory Across Sessions

Your agent learns a user's timezone, their preferred tone, the project they're working on — then the conversation ends and all of it is gone. This guide fixes that in three API calls. About ten minutes.

What You Will Build

An agent that loads everything it already knows at the start of a conversation, and saves anything new it learns at the end. The user stops repeating themselves.

Prerequisites

  • A RapidAPI key for Agent Memory API
  • Python 3.9+ with httpx, or Node 18+
  • An identifier for your agent — any stable string, e.g. support-bot-001

Authentication

Every request carries your key. Through the RapidAPI gateway:

import os, httpx

BASE = "https://agent-memory-api.boirama.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}
AGENT_ID = "support-bot-001"

Step 1 — Register Your Agent

Idempotent, so call it on every boot. Registration is what lets other agents grant this one access later.

httpx.post(f"{BASE}/v1/agents", headers=HEADERS, json={
    "agent_id": AGENT_ID,
    "display_name": "Acme Support Bot",
    "framework": "langchain",
})

Step 2 — Load Context When a Conversation Starts

Before your first LLM call, ask what you already know. Use a natural-language query, not keywords.

def load_context(user_id: str) -> str:
    r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
        "query": "what do I know about this user's preferences and situation",
        "agent_id": AGENT_ID,
        "namespace": f"acme-corp/users/{user_id}",
        "limit": 8,
    })
    r.raise_for_status()
    memories = r.json()["results"]
    if not memories:
        return ""
    lines = "\n".join(f"- {m['content']}" for m in memories)
    return f"What you already know about this user:\n{lines}"

context = load_context("user_8f3kLm92Xn")
# What you already know about this user:
# - Prefers email notifications over SMS
# - Works in the Europe/London timezone
# - Escalated a billing issue on 2026-08-14, resolved

Pass that string into your system prompt. That is the whole trick — recall produces prompt context, nothing more exotic.

Step 3 — Save What You Learned

Store one clear fact per call. Recall ranks individual facts, so a single long paragraph competes with itself and matches poorly.

def remember(user_id: str, fact: str, ttl_days: int | None = None):
    payload = {
        "content": fact,
        "agent_id": AGENT_ID,
        "namespace": f"acme-corp/users/{user_id}",
        "scope": "user",
        "subject_id": user_id,
    }
    if ttl_days:
        payload["ttl_seconds"] = ttl_days * 86400
    r = httpx.post(f"{BASE}/v1/memories", headers=HEADERS, json=payload)
    r.raise_for_status()
    return r.json()["memory_id"]

remember("user_8f3kLm92Xn", "Prefers email notifications over SMS")
remember("user_8f3kLm92Xn", "Currently migrating from Zendesk, finishes October 2026", ttl_days=120)
Write facts that stand alone. "Prefers email over SMS" is recallable in six months. "He said he likes the first one" is not — there is no conversation around it any more.

Complete Working Example

import os, httpx

BASE = "https://agent-memory-api.boirama.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}
AGENT_ID = "support-bot-001"


class AgentMemory:
    def __init__(self, user_id: str):
        self.ns = f"acme-corp/users/{user_id}"
        self.user_id = user_id
        httpx.post(f"{BASE}/v1/agents", headers=HEADERS,
                   json={"agent_id": AGENT_ID, "framework": "custom"})

    def load(self, limit: int = 8) -> str:
        try:
            r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
                "query": "what do I know about this user",
                "agent_id": AGENT_ID, "namespace": self.ns, "limit": limit,
            }, timeout=5.0)
            r.raise_for_status()
        except httpx.HTTPError:
            return ""   # an agent with no memory still works
        results = r.json()["results"]
        return "\n".join(f"- {m['content']}" for m in results)

    def save(self, fact: str, ttl_days: int | None = None) -> str | None:
        payload = {"content": fact, "agent_id": AGENT_ID, "namespace": self.ns,
                   "scope": "user", "subject_id": self.user_id}
        if ttl_days:
            payload["ttl_seconds"] = ttl_days * 86400
        try:
            r = httpx.post(f"{BASE}/v1/memories", headers=HEADERS,
                           json=payload, timeout=5.0)
            r.raise_for_status()
            return r.json()["memory_id"]
        except httpx.HTTPError:
            return None


mem = AgentMemory("user_8f3kLm92Xn")
system_prompt = f"You are a support agent.\n\n{mem.load()}"
# ... run your LLM turn ...
mem.save("Asked about SAML SSO on the Enterprise plan")

TypeScript Version

const BASE = "https://agent-memory-api.boirama.workers.dev";
const headers = {
  "X-RapidAPI-Key": process.env.RAPIDAPI_KEY!,
  "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
  "Content-Type": "application/json",
};
const AGENT_ID = "support-bot-001";

export async function loadContext(userId: string): Promise {
  const params = new URLSearchParams({
    query: "what do I know about this user",
    agent_id: AGENT_ID,
    namespace: `acme-corp/users/${userId}`,
    limit: "8",
  });
  try {
    const res = await fetch(`${BASE}/v1/memories?${params}`, { headers });
    if (!res.ok) return "";
    const { results } = await res.json();
    return results.map((m: any) => `- ${m.content}`).join("\n");
  } catch {
    return "";
  }
}

export async function remember(userId: string, fact: string, ttlDays?: number) {
  await fetch(`${BASE}/v1/memories`, {
    method: "POST",
    headers,
    body: JSON.stringify({
      content: fact,
      agent_id: AGENT_ID,
      namespace: `acme-corp/users/${userId}`,
      scope: "user",
      subject_id: userId,
      ...(ttlDays ? { ttl_seconds: ttlDays * 86400 } : {}),
    }),
  });
}

Error Handling

StatusCauseFix
401Missing or wrong keyHeader is X-RapidAPI-Key, not Authorization, through the gateway
413Content over 8,000 charsSplit into several facts
429Quota exhaustedBack off using Retry-After

Wrap both calls in try/except and degrade to an empty context. Memory is an enhancement; a failed recall should never surface as an error to your user.
