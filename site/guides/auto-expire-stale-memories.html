Auto-Expire Stale Memories with TTL

An agent that remembers everything forever is almost as broken as one that remembers nothing. Last quarter's pricing, a resolved outage, a contact who left the company — all of it keeps surfacing in recall and quietly poisoning answers. This guide gives facts a shelf life.

What You Will Build

A memory-writing layer that classifies facts by how long they stay true, plus an understanding of how ranking already down-weights old material even before it expires. Ten minutes.

Prerequisites

  • A RapidAPI key for Agent Memory API
  • Python 3.9+ with httpx

Authentication

import os, httpx

BASE = "https://agent-memory-api.YOUR-NAME.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}

Two Mechanisms, Not One

Staleness is handled in two independent ways, and they solve different problems:

MechanismWhat it doesUse it for
ttl_secondsHard expiry. After the deadline the memory stops appearing in recall entirely.Facts with a known end date
Salience decayGradual. Importance falls exponentially with time since last access, and rises with recall frequency. Automatic, nothing to configure.Facts that fade in relevance rather than expiring

Decay has roughly a 46-day half-life for untouched memories. A fact recalled regularly never decays, because each recall resets the clock and reinforces it.

Step 1 — Classify by Shelf Life

Do this once and apply it everywhere you write. The categories matter more than the exact numbers.

TTL = {
    "permanent":  None,            # name, timezone, language, allergies
    "annual":     365 * 86400,     # contract terms, fiscal calendar
    "quarterly":   90 * 86400,     # current project, active goals
    "monthly":     30 * 86400,     # preferences that drift, current sprint
    "ephemeral":         3600,     # in-conversation scratch state
}

Step 2 — Write with a TTL

def remember(content: str, agent_id: str, namespace: str,
             shelf_life: str = "permanent", importance: float | None = None):
    payload = {"content": content, "agent_id": agent_id, "namespace": namespace}
    ttl = TTL[shelf_life]
    if ttl:
        payload["ttl_seconds"] = ttl
    if importance is not None:
        payload["importance"] = importance

    r = httpx.post(f"{BASE}/v1/memories", headers=HEADERS, json=payload)
    r.raise_for_status()
    return r.json()


# Permanent: still true in five years
remember("User's primary language is Setswana", "support-bot-001",
         "acme-corp/users/prefs", "permanent")

# Quarterly: true now, probably not in six months
remember("Currently migrating from Zendesk; go-live targeted for Q4 2026",
         "support-bot-001", "acme-corp/users/projects", "quarterly")

# Ephemeral: dies with the conversation
remember("User is comparing the Pro and Team plans in this session",
         "support-bot-001", "acme-corp/sessions", "ephemeral")

The response tells you exactly when it dies:

{
  "memory_id": "7c1e9a04-3b2f-4d18-9f55-0a8e2c6b41d7",
  "status": "created",
  "namespace": "acme-corp/users/projects",
  "importance": 0.72,
  "expires_at": "2026-12-23T14:02:11Z",
  "tokens_used": 14,
  "cost_usd": 0.001
}

Step 3 — Let Dedupe Handle Corrections

When a fact changes, write the new version to the same namespace and agent. Near-identical content updates the existing memory rather than creating a rival copy, so recall never has to choose between two contradictory facts.

remember("Currently migrating from Zendesk; go-live targeted for Q4 2026",
         "support-bot-001", "acme-corp/users/projects", "quarterly")
# -> {"status": "created", "memory_id": "7c1e9a04-..."}

remember("Currently migrating from Zendesk; go-live slipped to Q1 2027",
         "support-bot-001", "acme-corp/users/projects", "quarterly")
# -> {"status": "updated", "memory_id": "7c1e9a04-..."}   same ID

Pass "dedupe": false when you deliberately want both versions — an audit log of changing state, for instance.

For a flat contradiction, delete rather than overwrite. If the user says "that was never true", call DELETE /v1/memories/{id}. Storing a correction next to a wrong fact leaves both in recall, and nothing tells the model which one wins.

Step 4 — Verify Expiry Is Working

r = httpx.get(f"{BASE}/v1/stats", headers=HEADERS)
s = r.json()

print(f"active:  {s['active_memories']}")
print(f"expired: {s['expired_memories']}")
for ns in s["namespaces"][:5]:
    print(f"  {ns['namespace']}: {ns['count']} (avg importance {ns['avg_importance']:.2f})")

A namespace growing without bound is usually one where everything is being written as permanent. An expired count of zero after weeks of use means the same thing.

Filtering by Age at Read Time

Independently of TTL, restrict a recall to a date range:

r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
    "query": "what changed on the Acme account",
    "agent_id": "support-bot-001",
    "temporal_window": "2026-08-01/2026-09-24",
})

Or drop anything whose salience has already decayed below a floor:

r = httpx.get(f"{BASE}/v1/memories", headers=HEADERS, params={
    "query": "active commitments for this customer",
    "agent_id": "support-bot-001",
    "min_importance": 0.4,
})

Complete Working Example

import os, httpx

BASE = "https://agent-memory-api.YOUR-NAME.workers.dev"
HEADERS = {
    "X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"],
    "X-RapidAPI-Host": "agent-memory-api.p.rapidapi.com",
    "Content-Type": "application/json",
}

TTL = {"permanent": None, "annual": 365 * 86400, "quarterly": 90 * 86400,
       "monthly": 30 * 86400, "ephemeral": 3600}


class ShelfLifeMemory:
    def __init__(self, agent_id: str, namespace: str):
        self.agent_id, self.namespace = agent_id, namespace

    def write(self, content: str, shelf_life: str = "permanent", **kw) -> str | None:
        payload = {"content": content, "agent_id": self.agent_id,
                   "namespace": self.namespace, **kw}
        if TTL[shelf_life]:
            payload["ttl_seconds"] = TTL[shelf_life]
        try:
            r = httpx.post(f"{BASE}/v1/memories", headers=HEADERS,
                           json=payload, timeout=5.0)
            r.raise_for_status()
            return r.json()["memory_id"]
        except httpx.HTTPError:
            return None

    def forget(self, memory_id: str) -> bool:
        r = httpx.delete(f"{BASE}/v1/memories/{memory_id}", headers=HEADERS,
                         params={"agent_id": self.agent_id})
        return r.json().get("status") == "deleted"

    def health(self) -> dict:
        return httpx.get(f"{BASE}/v1/stats", headers=HEADERS,
                         params={"agent_id": self.agent_id}).json()


mem = ShelfLifeMemory("support-bot-001", "acme-corp/users/prefs")
mem.write("Primary language is Setswana", "permanent")
mem.write("Evaluating the Team plan this month", "monthly", importance=0.6)
print(mem.health()["expired_memories"])
